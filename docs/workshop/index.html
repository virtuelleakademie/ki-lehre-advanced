Building Personalized Worked Example Generators with AI

Demonstrating Cognitive Load Theory Principles through PydanticAI

Workshop Overview

Welcome to this 3-hour workshop on building AI-powered educational tools grounded in Cognitive Load Theory. You’ll create a complete, production-ready application that generates personalized worked examples tailored to individual learners’ interests, goals, and contexts.

What You’ll Build

A Personalized Worked Example Generator that:

  • Collects learner profile information (name, domain, interests, hobbies, goals, skill level)
  • Generates customized worked examples in three domains: Programming (Python), Health Sciences (Statistics), or Agronomy
  • Weaves learner interests naturally into educational content
  • Provides step-by-step solutions with personal relevance
  • Deploys as a live web application on HuggingFace Spaces

Learning Objectives

By the end of this workshop, you will:

  1. Understand the worked example effect and personalization principle from Cognitive Load Theory
  2. Build a working personalized example generator using PydanticAI
  3. Deploy an interactive demo to HuggingFace Spaces
  4. Possess a template for creating domain-specific educational tools

Pedagogical Foundation

This workshop is grounded in Cognitive Load Theory (Sweller, 1988), specifically:

The Worked Example Effect:

“A ‘worked example’ is a problem that has already been solved for the learner, with every step fully explained and clearly shown. The ‘worked example effect’ is the widely replicated finding that novice learners who are given worked examples to study perform better on subsequent tests than learners who are required to solve the equivalent problems themselves.”

— NSW CESE (2017, p. 7)

Why It Works:

  • Unguided problem-solving overloads working memory
  • Studying worked examples reduces cognitive load
  • More working memory capacity available for schema construction
  • Better learning outcomes for novices

Our Addition - Personalization:

  • Familiar contexts reduce extraneous cognitive load
  • Personal relevance increases germane load (motivation)
  • Better schema formation and transfer

Workshop Structure: A Worked Example Approach

Important🔄 This Workshop IS a Worked Example

This workshop demonstrates the principle it teaches by being structured as a worked example itself.

Traditional approach (problem-solving):

Give you requirements → You struggle to build → Instructor helps when stuck

High cognitive load, potential frustration, pattern harder to see

Our approach (worked example):

Show complete solution → Study each component → Explain design choices → Apply to your domain

Lower cognitive load, clearer pattern, better transfer

Why? Most of you are novices at building educational AI tools. Research shows studying worked examples is more effective than unguided problem-solving for novices.

The Five Phases

  1. PRESENT (Part 1-2) - See the complete, working solution
  2. STUDY (Part 3) - Examine how each component works
  3. UNDERSTAND (Part 4) - Connect design to learning science
  4. APPLY (Part 5) - Deploy and customize
  5. TRANSFER (Closing) - Plan tools for your own teaching context

Fading Scaffolding

Notice how support gradually decreases:

  • Part 1-2: Heavy guidance, complete explanations
  • Part 3-4: More independence, you make small modifications
  • Part 5: You apply the pattern with minimal guidance
  • After: You transfer to new domains independently
Tip💡 Meta-Learning Moment

As you progress through today, notice:

  • When does studying the complete solution help vs. confuse?
  • When do you want to start experimenting on your own?
  • How does seeing the “big picture” first affect your understanding?

These insights will inform how YOU design worked examples for your students.

Technical Stack

Core Technologies

  • Marimo - Reactive Python notebooks with built-in UI
  • PydanticAI - Type-safe AI agent framework
  • Pydantic - Data validation using Python type hints
  • OpenAI GPT-4o - Language model for generation
  • HuggingFace Spaces - Free deployment platform

Why These Choices?

Marimo over Jupyter/Colab:

  • Reactive updates (no stale state)
  • Better developer experience
  • Production-ready (can deploy as apps)
  • Git-friendly (pure Python files)

PydanticAI over raw OpenAI:

  • Type safety with Pydantic models
  • Structured outputs guaranteed
  • Cleaner, more maintainable code
  • Better error handling

HuggingFace Spaces:

  • Free hosting for educational demos
  • Docker + Marimo template available
  • Easy sharing with students/colleagues

Three Learning Domains

The tool supports three domains, each with 5-6 concepts:

1. Programming (Python)

  • For loops
  • List comprehensions
  • Dictionary methods
  • Functions with parameters
  • String formatting

Example Context: Building a recipe website, photography portfolio, gaming tools

2. Health Sciences (Statistics)

  • Mean and standard deviation
  • Correlation analysis
  • Linear regression
  • Independent t-tests
  • Confidence intervals
  • Effect size (Cohen’s d)

Example Context: Sports performance, nutrition tracking, patient outcomes

3. Agronomy (Agricultural Science)

  • Yield prediction
  • NPK optimization
  • Growing degree days
  • Water use efficiency
  • Cost-benefit analysis

Example Context: Family farms, specific crops, sustainable agriculture

Connection to Learning Science

This workshop demonstrates several evidence-based learning principles:

Note📚 Make It Stick Connections

This tool addresses multiple strategies from Make It Stick (Brown, Roediger, & McDaniel, 2014):

  1. Worked Examples - Reduce cognitive load for novices
  2. Variation - Practice in different personal contexts
  3. Understanding vs. Familiarity - Personalization helps distinguish the two
  4. Application - Real-world contexts for transfer
