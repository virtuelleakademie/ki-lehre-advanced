Build: Hands-On with the Starter Template

Duration: 90 minutes

  • Access the app (2 min)
  • Code walkthrough (20 min)
  • Modify concepts (50 min)
  • Test and refine (15 min)
  • Reflection (3 min)

Learning Objectives

By the end of this section, you will:

  1. Understand the code structure of the worked example generator
  2. Modify the template to add new concepts (in your browser)
  3. Recognise the pattern for building educational AI tools
  4. See how Pydantic and Marimo create structured outputs
ImportantRealistic Expectations

What this section is: A hands-on learning exercise to understand the pattern and possibilities

What this section is not: Training to become a Python developer or deploy production apps

Your goal: Understand how these tools work and what’s involved in building them. If you want to create your own later, the Resources section provides deployment guides for self-directed learning.

Part 1: Access the App (2 minutes)

Open the Workshop Space

No installation required. Everything runs in your browser.

Access the Interactive App

URL: https://huggingface.co/spaces/virtuelleakademie/workshop-starter

What you’ll see:

  • Interactive marimo notebook
  • Code cells (some editable, some read-only)
  • Live UI components
  • Reactive updates

First time? The Space may take 20-30 seconds to wake up. Be patient.

Orient Yourself

When the app loads, you’ll see:

  • Code cells at the top (imports, data models, concept library, AI agent)
  • UI components below (profile inputs, concept selector, generate button)
  • Output area at the bottom (generated examples appear here)

Each browser session is isolated: your changes won’t affect other participants.

Part 2: Code Walkthrough (20 minutes)

App Structure

Scroll through the code cells to see the overall structure:

# 1. Imports and setup
# 2. Data models (Pydantic)
# 3. Concept library (ONE domain)
# 4. AI agent configuration
# 5. Generation function
# 6. Marimo UI cells

Your task: Read through the code, following along with this walkthrough. Don’t edit yet - focus on understanding.

Key Components

1. Data Models (Lines 10-60)

LearnerProfile: What we collect

class LearnerProfile(BaseModel):
    name: str
    domain: Literal["programming"]  # Only 1 domain
    specific_interest: str
    hobby_or_passion: str
    goal: str
    background_level: Literal["beginner", "intermediate", "advanced"]

PersonalizedWorkedExample: What AI generates

class PersonalizedWorkedExample(BaseModel):
    title: str
    problem_statement: str
    given_data: str
    step_by_step_solution: list[str]  # Multiple steps
    final_answer: str
    connection_to_goal: str
    practice_suggestion: str

Why Pydantic? - Type safety - guarantees AI returns what we expect - Validation - catches errors before they reach users - Documentation - clear structure

2. Concept Library (Lines 62-100)

CONCEPTS = {
    "programming": [
        {
            "name": "For Loops",
            "abstract": "Iterate through a sequence",
            "difficulty": "beginner",
            "typical_use": "Process lists, repeat actions"
        },
        {
            "name": "Functions with Parameters",
            "abstract": "Reusable code blocks with inputs",
            "difficulty": "beginner",
            "typical_use": "Organize code, avoid repetition"
        },
        {
            "name": "String Formatting",
            "abstract": "Create formatted text with f-strings",
            "difficulty": "beginner",
            "typical_use": "Display data, create messages"
        }
    ]
}

Structure: - Each concept has: name, abstract, difficulty, typical use - Easy to add new concepts (we’ll do this!) - Can add new domains by extending the dictionary

3. AI Agent (Lines 102-140)

example_generator = Agent(
    'openai:gpt-5.1',           # Model to use
    result_type=PersonalizedWorkedExample,  # Structured output
    system_prompt="""You are an expert educator...

    Create personalized worked examples that:
    1. Weave learner's interests naturally
    2. Use their name throughout
    3. Make data realistic
    4. Connect to their goal
    """
)

Key features: - result_type ensures structured output (Pydantic model) - System prompt guides AI behavior - Model choice affects cost/quality

4. Generation Function (Lines 142-180)

async def generate_example(profile, concept):
    prompt = f"""
    Create a worked example for:

    LEARNER: {profile.name}
    INTEREST: {profile.specific_interest}
    HOBBY: {profile.hobby_or_passion}
    GOAL: {profile.goal}
    LEVEL: {profile.background_level}

    CONCEPT: {concept['name']}
    ...
    """

    result = await example_generator.run(prompt)
    return result.data  # Returns PersonalizedWorkedExample

5. Marimo UI Cells (Lines 182-end)

Marimo creates reactive cells:

  • @app.cell decorator
  • Auto-updates when dependencies change
  • No stale state (unlike Jupyter)

UI components:

  • mo.ui.text() - Text inputs
  • mo.ui.dropdown() - Concept selection
  • mo.ui.button() - Generate button
  • mo.md() - Markdown display

Part 3: Modify - Add Concepts (50 minutes)

Your Task

Add 1-2 new concepts to the Programming domain by editing code cells in your browser.

Suggested concepts:

  • List Comprehensions
  • Dictionary Methods
  • File I/O
  • Error Handling
  • Object-Oriented Programming basics

Step-by-Step Instructions

1. Choose Your Concepts

Beginner concepts:

  • Variables and data types
  • Conditional statements (if/else)
  • Basic list operations
  • File reading/writing

Intermediate concepts:

  • List comprehensions
  • Dictionary methods
  • Lambda functions
  • Exception handling

2. Find the CONCEPTS Cell

Scroll to the editable cell containing the CONCEPTS dictionary:

CONCEPTS = {
    "programming": [
        {
            "name": "For Loops",
            ...
        },
        {
            "name": "Functions with Parameters",
            ...
        },
        {
            "name": "String Formatting",
            ...
        }
        # ADD YOUR CONCEPTS HERE!
    ]
}

This cell is editable: click inside it to make changes.

3. Add Your Concept

Click in the cell and add your new concept to the list:

        {
            "name": "List Comprehensions",
            "abstract": "Create new lists using concise syntax",
            "difficulty": "intermediate",
            "typical_use": "Transform data, filter lists elegantly"
        },

Important: Don’t forget the comma after the closing brace!

Try It: Add Your First Concept

  1. Choose a programming concept you teach
  2. Write the abstract (1 sentence - what it does)
  3. Set difficulty level (beginner/intermediate/advanced)
  4. Describe typical use (when to use it)
  5. Edit the cell to add your concept
  6. Run the cell (click the play button or Shift+Enter)

4. Customise the System Prompt (Optional)

Want more control over how AI generates examples?

Find the system prompt cell (marked as editable):

system_prompt="""You are an expert educator...
"""

Modifications you could make:

  • Add emphasis on code comments
  • Request specific programming style
  • Add warnings about common errors
  • Include best practices

Example addition:

system_prompt="""You are an expert educator...

IMPORTANT: For programming examples:

- Include detailed code comments
- Mention common pitfalls
- Show best practices
- Use modern Python syntax (f-strings, type hints)
"""

5. Run the Cell

After editing:

  1. Click the Run button (or press Shift+Enter)
  2. Marimo automatically updates dependent cells
  3. New concepts appear in the dropdown below
  4. Watch the reactive magic happen

Part 4: Test and Refine (15 minutes)

Generate Examples with Your Concepts

Individual Testing

Now test your modifications:

  1. Fill in your own profile:

    • Use YOUR name
    • YOUR specific interest in programming
    • YOUR hobby
    • YOUR goal

  2. Select one of YOUR new concepts

  3. Click Generate and wait (30-60 seconds)

  4. Review the generated example:

    • Does it use your personal context naturally?
    • Is the code correct and runnable?
    • Are the explanations clear?
    • Does it connect to your goal?

  5. Try different profiles:

    • Change the interest/hobby
    • See how examples change
    • Test different difficulty levels

Quality Checks

Good personalised example: - Uses learner’s name throughout - Data/scenario matches their interest - Code is correct and runnable - Explanations are clear - Explicitly connects to their goal

Signs of poor generation: - Generic example with name added superficially - Syntax errors in code - Forced connection to interest - Missing explanation steps

Iterate and Improve

If examples aren’t satisfactory:

  1. Check concept description: Is the “abstract” clear and concise?
  2. Adjust system prompt: Add more specific instructions
  3. Check difficulty: Does it match the learner level?
  4. Regenerate: AI output varies; try again

Common Issues & Solutions

Issue: Concept doesn’t appear in dropdown

Solution:

  • Check Python syntax (commas, brackets)
  • Ensure it’s inside “programming” array
  • Run the cell again (Shift+Enter)
  • Refresh the browser if needed

Issue: Generation fails with error

Possible causes:

# Missing comma between concepts
{
    "name": "For Loops",
    ...
}  # <- Need comma here!
{
    "name": "List Comprehensions",
    ...
}

What to do: Edit the cell, add the missing comma, run again.

Issue: Examples are too generic

Solution: Enhance system prompt cell:

system_prompt="""...

CRITICAL: Weave interests NATURALLY into the problem.
Bad: "Calculate sum of recipe ingredients"
Good: "You're building a recipe cost calculator for your
baking blog. Here's how to sum ingredient costs..."
"""

Then run the cell to update the agent configuration.

Issue: Slow generation or timeout

Causes:

  • GPT-5.1 can take 30-60 seconds
  • Multiple users generating simultaneously
  • HuggingFace Space waking from sleep

What to do: Be patient. If it fails, try again.

Reflection (3 minutes)

What You’ve Learned

Take a moment to consider:

  1. Code Structure: Can you identify the key components?
    • Data models (Pydantic)
    • Concept library (dictionary)
    • OpenAI API with structured outputs
    • UI components (Marimo)
  2. The Pattern: What would you need to build your own tool?
    • Define your domain and concepts
    • Create data models for inputs/outputs
    • Configure AI agent with system prompt
    • Build UI for interaction
  3. Pedagogical Principles: How does this reduce cognitive load?
    • Structured outputs (predictable format)
    • Personalised contexts (familiar to learner)
    • Complete worked examples (not problem-solving)

Checkpoint Questions

Can you answer: - Where do you add new concepts? - What does result_type=PersonalizedWorkedExample do? - How does personalisation reduce cognitive load?

Can you do: - Add a new concept to the library? - Generate an example with your own profile? - Modify the system prompt?

Have you recognised: - This isn’t about becoming a Python developer - It’s about understanding what’s possible - The pattern can be adapted to many domains
