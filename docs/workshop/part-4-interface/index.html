Quick Reactivity Demo

Note💻 Live Demo (5 minutes)

Instructor demonstrates reactivity:

import marimo as mo

# Create a text input
name = mo.ui.text(label="Your name:")
name  # Display it

# In another cell - automatically updates when name changes!
if name.value:
    mo.md(f"Hello, **{name.value}**!")

Key Concepts:

  • Reactive: When name.value changes, dependent cells auto-update
  • No hidden state: Dependencies are tracked automatically
  • Display: Just reference the variable to show it
  • mo.md(): Render markdown (including formatting)

Activity 1: Build Profile Input Form

Note💻 Live Coding (15 minutes)

We’ll create all input widgets for collecting learner profiles.

Creating Input Widgets

import marimo as mo

# Text input for name
name_input = mo.ui.text(
    label="Your first name:",
    placeholder="e.g., Maria",
    full_width=True
)

# Dropdown for domain selection
domain_input = mo.ui.dropdown(
    label="Choose your learning domain:",
    options={
        "Programming (Python)": "programming",
        "Health Sciences (Statistics)": "health_sciences",
        "Agronomy (Agricultural Science)": "agronomy"
    },
    value=None,  # Nothing selected initially
    full_width=True
)

# Text input for specific interest
interest_input = mo.ui.text(
    label="Your specific interest in this domain:",
    placeholder="e.g., web development, sports nutrition, coffee farming",
    full_width=True
)

# Text input for hobby
hobby_input = mo.ui.text(
    label="A hobby or passion you have:",
    placeholder="e.g., photography, cycling, cooking",
    full_width=True
)

# Text input for goal
goal_input = mo.ui.text(
    label="What you want to achieve:",
    placeholder="e.g., build a portfolio site, improve performance, increase yield",
    full_width=True
)

# Dropdown for level
level_input = mo.ui.dropdown(
    label="Your current level:",
    options=["beginner", "intermediate", "advanced"],
    value="beginner",  # Default to beginner
    full_width=True
)

Displaying the Form

Use mo.vstack() to stack elements vertically:

mo.vstack([
    mo.md("## 👤 Tell Us About Yourself"),
    name_input,
    domain_input,
    interest_input,
    hobby_input,
    goal_input,
    level_input
])
Tip💡 Marimo UI Components

Text input: mo.ui.text()

Dropdown: mo.ui.dropdown()

Button: mo.ui.button()

Checkbox: mo.ui.checkbox()

Slider: mo.ui.slider()

More: See marimo.io/docs

Layouts:

  • mo.vstack() - Vertical stack
  • mo.hstack() - Horizontal stack
  • mo.callout() - Highlighted box

Activity 2: Add Dynamic Concept Selection

Note💻 Live Coding (10 minutes)

Now we’ll make the concept selector appear only when profile is complete, and show only relevant concepts for the chosen domain.

Check Profile Completion

# Check if all fields are filled
profile_complete = all([
    name_input.value,
    domain_input.value,
    interest_input.value,
    hobby_input.value,
    goal_input.value,
    level_input.value
])

Create Profile Object

if profile_complete:
    learner_profile = LearnerProfile(
        name=name_input.value,
        domain=domain_input.value,
        specific_interest=interest_input.value,
        hobby_or_passion=hobby_input.value,
        goal=goal_input.value,
        background_level=level_input.value
    )
else:
    learner_profile = None

Show Success Message

if profile_complete:
    mo.callout(
        f"""
        ✅ **Profile Complete!**

        Great, {learner_profile.name}! Now choose a concept below.
        """,
        kind="success"
    )
else:
    mo.callout(
        "📝 Please fill in all fields above to continue.",
        kind="info"
    )

Dynamic Concept Selector

if profile_complete and learner_profile:
    # Get concepts for the chosen domain
    available_concepts = CONCEPTS[learner_profile.domain]

    # Create dropdown with concept options
    concept_selector = mo.ui.dropdown(
        label=f"Choose a concept in {learner_profile.domain.replace('_', ' ').title()}:",
        options={
            f"{c['name']} ({c['difficulty']})": c
            for c in available_concepts
        },
        value=None,
        full_width=True
    )

    # Display with header
    mo.vstack([
        mo.md("## 📚 Choose a Concept to Learn"),
        concept_selector
    ])
else:
    concept_selector = None
Tip💡 Reactivity in Action

Notice what happens:

  1. User selects “Programming” → domain_input.value changes
  2. profile_complete recalculates
  3. learner_profile is created with the new domain
  4. concept_selector updates to show only Programming concepts
  5. UI re-renders automatically

No manual refresh needed! This is Marimo’s reactive magic.

Activity 3: Generate and Display Example

Note💻 Live Coding (10 minutes)

The final piece: a button to generate examples and a beautiful display.

Create Generate Button

if profile_complete and concept_selector and concept_selector.value:
    mo.md("---")  # Horizontal line

    generate_button = mo.ui.button(
        label="✨ Generate My Personalized Example",
        kind="success",
        full_width=True
    )

    generate_button  # Display it
else:
    generate_button = None

Generate on Button Click

# This cell is async because generation takes time
async def generate_and_display():
    if generate_button and generate_button.value and learner_profile and concept_selector.value:

        # Show loading spinner
        with mo.status.spinner(title="Creating your personalized example... This may take 30-60 seconds."):
            try:
                example = await generate_personalized_example(
                    profile=learner_profile,
                    concept=concept_selector.value
                )

                # Display the formatted example
                return mo.vstack([
                    mo.md("---"),
                    mo.md(f"# {example.title}"),
                    mo.md("## 📋 The Problem"),
                    mo.md(example.problem_statement),
                    mo.md("### Given Data"),
                    mo.md(example.given_data),
                    mo.md("---"),
                    mo.md("## 💡 Step-by-Step Solution"),
                    *[mo.md(f"**Step {i}:**\n\n{step}")
                      for i, step in enumerate(example.step_by_step_solution, 1)],
                    mo.md("---"),
                    mo.md("## ✅ Final Answer"),
                    mo.md(example.final_answer),
                    mo.md("---"),
                    mo.callout(
                        f"### 🎯 Why This Matters for You\n\n{example.connection_to_goal}",
                        kind="success"
                    ),
                    mo.md("---"),
                    mo.callout(
                        f"### 🚀 Try This Next\n\n{example.practice_suggestion}",
                        kind="info"
                    ),
                ])

            except Exception as e:
                return mo.callout(
                    f"❌ Error generating example: {str(e)}\n\nPlease check your OpenAI API key.",
                    kind="danger"
                )

# Run the async function
await generate_and_display()
Tip💡 Advanced Marimo Features

Loading states: mo.status.spinner()

  • Shows progress during long operations
  • Better UX than frozen interface

Callouts: mo.callout(kind=...)

  • success - Green, for positive messages
  • info - Blue, for information
  • warning - Yellow, for cautions
  • danger - Red, for errors

Dynamic lists: *[...]

  • Unpack list of elements into vstack
  • Useful for variable-length content (like solution steps)

Error handling: try/except

  • Always catch API errors
  • Show helpful messages to users

Complete Application Flow

Let’s review what we’ve built:

1. User fills in profile form
   ↓
2. Form validates (all fields filled?)
   ↓
3. Profile object created
   ↓
4. Concept selector appears (domain-specific)
   ↓
5. User selects concept
   ↓
6. Generate button appears
   ↓
7. User clicks button
   ↓
8. Loading spinner shows
   ↓
9. AI generates personalized example (30-60 sec)
   ↓
10. Formatted example displays with all sections

Putting It All Together

The complete marimo notebook file (app.py) contains approximately 15-20 cells in this order:

  1. Imports cell - Import all libraries
  2. Models cell - Define Pydantic models
  3. Concepts cell - CONCEPTS dictionary
  4. Agent cell - Create PydanticAI agent
  5. Generation function cell - Define async generation function
  6. Profile form cells (multiple) - Input widgets
  7. Profile validation cell - Check completion
  8. Concept selector cell - Dynamic dropdown
  9. Generate button cell - Trigger button
  10. Display cell - Format and show output
Important🎯 Key Learning

Marimo’s reactivity means you can focus on what to display, not when to update. The framework handles dependencies automatically.

This makes building educational applications much faster than traditional web frameworks!
