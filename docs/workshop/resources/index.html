Deployment Guide (For the Curious)

NoteDeploy Your Own Version

If you want to deploy your modified version to HuggingFace Spaces (self-directed learning):

  1. Create free account: huggingface.co
  2. Follow deployment guide: hf-spaces/worked-example-weaver/DEPLOYMENT.md
  3. Takes approximately 10 minutes once set up

Why deploy?

  • Students can access without installing anything
  • Shareable link for your course
  • Professional demonstration
  • No local setup required

When NOT to deploy:

  • Just testing/learning
  • Only for personal use
  • Want to modify frequently
  • Prefer local control

Note: This is entirely optional. The workshop showed you the pattern; deployment is for those who want to create their own version for actual use with students.

Extension Ideas

Add New Domains

Template for new domain:

CONCEPTS = {
    "your_domain_name": [
        {
            "name": "Concept 1 Name",
            "abstract": "One-sentence description",
            "difficulty": "beginner",  # or intermediate, advanced
            "typical_use": "When students would use this"
        },
        # Add 3-5 more concepts
    ]
}

Example domains to add: - Physics (kinematics, forces, energy conservation) - Chemistry (balancing equations, stoichiometry, molarity) - Economics (supply/demand, elasticity, comparative advantage) - Biology (cell processes, genetics, evolution) - Mathematics (algebra, calculus, probability)

Add New Features

Assessment integration:

# Generate practice problems (not worked examples)
class PracticeProblem(BaseModel):
    problem_statement: str
    hints: list[str]          # Progressive hints
    final_solution: str       # Hidden initially

# Faded worked examples
class FadedExample(BaseModel):
    problem: str
    step_1: str               # Shown
    step_2: str               # Shown
    step_3_incomplete: str    # Student completes
    step_4_blank: str         # Student writes

Difficulty adaptation:

# Track student performance
def adjust_difficulty(correct_rate):
    if correct_rate > 0.8:
        return "increase"
    elif correct_rate < 0.5:
        return "decrease"
    return "maintain"

Cost Considerations

OpenAI API Pricing (as of 2025)

GPT-5.1:

  • Input: ~$0.003 per 1K tokens
  • Output: ~$0.015 per 1K tokens
  • Typical example: ~$0.02-0.05 each

Strategies to reduce costs:

  1. Use cheaper models for simple concepts

    # GPT-4o is cheaper, still good quality
example_generator = Agent('openai:gpt-4o', ...)

  2. Cache common examples

    # Generate once, reuse many times
example_cache = {}

  3. Batch generation

    # Generate all examples for semester upfront
# One-time cost, unlimited reuse

  4. Educational discounts

    • OpenAI offers educational pricing
    • Contact: education@openai.com
    • Institutional accounts available

Ethical Considerations

Using AI in Education

Best practices:

  1. Transparency
    • Tell students examples are AI-generated
    • Explain the pedagogical purpose
    • Discuss limitations
  2. Quality Control
    • Review generated examples before sharing
    • Check for errors or bias
    • Verify code runs correctly
  3. Balanced Use
    • Pair with problem-solving practice
    • Don’t replace all traditional teaching
    • Use to reduce load, not replace thinking
  4. Data Privacy
    • Don’t include personally identifiable info in prompts
    • Review OpenAI’s data usage policy
    • Consider institutional agreements
  5. Equity
    • Ensure all students have access
    • Provide alternatives for those who opt out
    • Don’t create advantage for some
