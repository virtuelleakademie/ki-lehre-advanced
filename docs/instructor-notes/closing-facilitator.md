## Zeitbudget (15 min)

| Min | Phase | Aktivität |
|-----|-------|-----------|
| 0:00-0:03 | Leitsatz-Erweiterung | Kernsatz vorlesen, eine Pause halten |
| 0:03-0:08 | Downstream-Uses-Gallery | Vier weitere Einsätze des Specs benennen |
| 0:08-0:13 | Persönliche Verpflichtung | Aufgabe, Schritt, Datum aufschreiben; mit Partnerin teilen |
| 0:13-0:15 | Take-Home-Pointer und Verabschiedung | URL und Ressourcen zeigen |

## Eröffnung Closing

> Drei Stunden haben wir an einer Teilaufgabe deiner Lehre gearbeitet. Was ihr in der Hand habt, ist nicht ein Workshop-Notiz, sondern ein dauerhaftes Artefakt. Wir schliessen mit drei Bewegungen: eine Verallgemeinerung, eine Aussicht auf weitere Einsätze, eine Verpflichtung.

Direkt zur Leitsatz-Slide.

## Die Leitsatz-Erweiterung (3 min)

Wortlaut verbatim, mit Pausen:

> *Das Spec ist dauerhaft, das Werkzeug ist Rendering. Dieselbe Spezifikation kann ein Scaffolding-Tool, eine Lernende-Simulation oder einen Diagnosetest treiben. Wenn nächstes Jahr ein neues Modell oder Tool kommt, bleibt das Spec gleich.*

Eine 5-Sekunden-Pause halten. Dann:

> Das Werkzeug, das ihr in Block 3 gesehen habt, ist eines von vielen möglichen Renderings. Wir zeigen euch jetzt vier weitere.

## Downstream-Uses-Gallery (5 min)

Eine Slide mit vier nummerierten Einträgen, je eine Zeile:

1. **Worked-Example-Generator:** Spec rein, ausgearbeitete Lösungsbeispiele raus, mit Warnhinweisen an den Misconception-Stellen.
2. **Misconception-Probe:** Spec rein, Diagnosefragen raus, die genau die antizipierten Misconceptions aktivieren.
3. **Formative Assessment Generator:** Spec rein, Quiz raus, das alle Skills abdeckt und Misconceptions sondiert.
4. **Knowledge-Tracing-Instrumentierung:** Spec als Q-Matrix für Mastery-Tracking-Systeme.

Pro Eintrag eine kurze Beschreibung. **Nicht vorführen.** Die Skizzen mit Prompt-Vorlagen liegen im [Take-Home: Weitere Werkzeuge](../workshop/take-home/weitere-werkzeuge.qmd). Wer interessiert ist, schaut nach.

## Persönliche Verpflichtung (5 min)

Klare Ansage:

> Schreibt auf Papier oder in eine Notiz drei Dinge: erstens die *eine konkrete Teilaufgabe*, an der ihr euer Spec anwenden werdet (nicht "ich werde nachdenken", sondern: diese spezifische Aufgabe). Zweitens *einen konkreten Schritt*. Drittens ein *Datum*.

Drei Minuten still schreiben lassen. Niemanden drängen, einen perfekten Schritt zu wählen. Auch ein kleiner Schritt zählt.

Dann:

> Sucht eure Partnerin aus Block 2. Erzählt ihr eure Verpflichtung in einem Satz. Sie schreibt sich euer Datum in den Kalender und meldet sich danach.

Der soziale Commitment-Effekt ist nicht trivial: eine ausgesprochene Verpflichtung wird signifikant häufiger eingehalten als eine nur gedachte.

## Häufige Stolperstellen und Redirects

**"Ich weiss nicht, welchen Schritt ich gehen soll."** Vier Optionen vorschlagen:

- Das Spec gegen drei reale Lernenden-Antworten testen (am direktesten);
- die Aufgabenstellung an einer Stelle anpassen, die das Spec als unklar entlarvt hat;
- den Worked-Example-Generator probieren (Prompt im Take-Home);
- eine Misconception-Probe entwerfen.

**"Das Datum ist mir unangenehm."** Erlaubnis geben, ein vorsichtiges Datum zu wählen. Drei Wochen ist genug. Lieber ein realistisches Datum, das gehalten wird, als ein optimistisches, das verpasst wird.

**"Meine Partnerin und ich kennen uns gar nicht."** Genau deshalb funktioniert das. Eine soziale Verpflichtung gegenüber jemandem, den du nicht kennst, fühlt sich verbindlicher an als eine gegenüber einer Freundin.

## Take-Home-Pointer (2 min)

Auf die [Take-Home-Seite](../workshop/take-home/index.qmd) zeigen. Vier Dinge:

- Das laufende Werkzeug (URL bleibt stabil)
- Die Architektur-Erklärung in plain Deutsch
- Vier Skizzen für weitere Werkzeuge mit Prompt-Vorlagen
- Optionale Hausaufgaben (Falsifikationsnotiz, Selbst-Tun-vs-Zuschauen-Tagging)

Dann verabschieden. Nicht in eine Q&A-Runde überleiten; die Teilnehmenden haben nach 3 Stunden mehr neue Information bekommen, als sie integrieren können.

## Typische Fragen am Ende

- *"Wo finde ich das Material nochmal?"* — Auf der Take-Home-Seite. URL bleibt stabil.
- *"Kann ich dich nach dem Workshop kontaktieren?"* — Ja. Mailadresse im Take-Home oder auf der Homepage.
- *"Gibt es einen Folgeworkshop?"* — Aktuell nicht geplant. Selbststudium über das CAS Lernpsychologie.

## Take-away Satz für das Closing

> Was du heute geschrieben hast, ist eine pädagogische Spezifikation, die mehrere Modellgenerationen überleben kann. Sie ist nicht das Endprodukt deiner Arbeit, sondern der Ausgangspunkt für die Iteration mit deinen realen Lernenden.

Verabschiedung. Türen offen für individuelle Fragen, aber kein offizielles Plenums-Q&A.
