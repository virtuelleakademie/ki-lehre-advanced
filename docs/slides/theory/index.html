Cognitive Load Theory Basics

Working Memory

  • Limited: 3-7 items at once
  • Volatile: Information decays quickly
  • Bottleneck: Gets overloaded with complex material
  • Problem: Learning new concepts can feel overwhelming

Long-Term Memory

  • Unlimited: No known capacity limits
  • Persistent: Information stored as schemas
  • Automatic: Accessed without conscious effort
  • Goal: Build rich, organized knowledge structures

The Challenge

How do we get information from working memory into long-term memory without overload?

The Novice Problem

Problem-solving for novices = cognitive overload

  • Must search for solution strategies
  • Must test each strategy
  • Must monitor progress
  • Must learn the concept
  • Too much for working memory!

Result

  • Frustration
  • Poor learning
  • Shallow understanding
  • Can’t transfer knowledge

Principle 1: The Worked Example Effect

The Research

“Novice learners who are given worked examples to study perform better on subsequent tests than learners who are required to solve the equivalent problems themselves.”

— NSW Centre for Education Statistics and Evaluation (2017, p. 7)

The Evidence

  • Effect size: 0.52 across multiple studies (Crissman, 2006)
  • Particularly strong for novices (Cooper & Sweller, 1987)
  • Diminishes as expertise grows (Kalyuga et al., 2003)
  • Replicated across domains: mathematics, programming, science

Why Worked Examples Work

Traditional Problem-Solving

High Cognitive Load:

  • Search for strategies
  • Test approaches
  • Monitor progress
  • Learn concept
  • Track errors

Little capacity left for learning!

Studying Worked Examples

Reduced Cognitive Load:

  • Solution is shown
  • Can focus on pattern
  • More capacity for schemas
  • Easier to see structure

Efficient learning!

Example: Learning For Loops

Problem-Solving Approach

“Write code to print numbers 1-10”

  • Where do I start?
  • What’s the syntax?
  • How do I increment?
  • Why isn’t it working?
  • What’s a range?

Worked Example Approach

# Print numbers 1 to 10
for i in range(1, 11):
    print(i)

Study this:

  • See the pattern
  • Understand range()
  • See the structure
  • Can now apply it

Principle 2: The Personalisation Effect

The Problem with Generic Examples

Generic example:

Calculate the correlation between Variable X and Variable Y.

X: [10, 15, 20, 25, 30]
Y: [2, 4, 6, 8, 10]

Cognitive load:

  • Must process abstract variables
  • No connection to existing knowledge
  • No personal relevance
  • Higher extraneous load

The Power of Personalisation

Personalised example:

You love cycling. Calculate the correlation between your
weekly training hours and your average speed:

Training hours: [10, 15, 20, 25, 30]
Average speed: [25, 27, 29, 31, 33] km/h

This will help you understand if more training
improves your performance.

Benefits:

  • Connects to existing knowledge (cycling)
  • Easier to process (familiar context)
  • More motivation (personal relevance)
  • Lower cognitive load

The Research Evidence

“Familiar contexts require less cognitive effort to process, reducing extraneous cognitive load and improving learning outcomes.”

— Cordova & Lepper (1996)

The Evidence

  • Increased motivation and engagement
  • Better learning outcomes with familiar contexts
  • Particularly effective when combined with worked examples
  • Reduces extraneous cognitive load

Two Types of Cognitive Load

Extraneous Load (BAD)

  • Processing irrelevant information
  • Unfamiliar contexts requiring interpretation
  • Confusing formats
  • Poor instructional design

Reduces learning!

Germane Load (GOOD)

  • Effort directed at learning
  • Schema construction
  • Deep processing of patterns
  • Understanding structures

Promotes learning!

Personalisation reduces extraneous load while maintaining germane load

How AI Enables This at Scale

The Traditional Challenge

Creating personalised worked examples is labor-intensive:

  • Must know each student’s interests
  • Must create unique examples for each concept
  • Must ensure quality and accuracy
  • Must maintain pedagogical soundness
  • Doesn’t scale beyond small classes

The Math

  • 30 students × 10 concepts = 300 unique examples
  • 15 minutes per example = 75 hours
  • Impossible to do manually!

The AI Solution

Large language models can:

  • Generate unique examples on demand
  • Weave personal contexts naturally
  • Maintain pedagogical quality (with structured outputs)
  • Scale to unlimited students
  • Generate in seconds, not hours

Today’s Goal

Build a tool that:

  1. Collects learner interests, hobbies, goals
  2. Generates personalised worked examples
  3. Teaches concepts through familiar contexts
  4. Uses PydanticAI to ensure structured, quality output

Why PydanticAI?

The Problem with Raw LLMs:

  • Get back unstructured text
  • Need to parse and validate manually
  • Prone to errors
  • Hard to use programmatically

The Solution: Structured Outputs

  • Define data models (Pydantic)
  • Guarantee structure (type safety)
  • Automatic validation
  • Easy to use in applications
